# 실판매 전 설정과 검토

이 구현은 모의 상태로 전달합니다. 실제 계좌·이메일 계정·도메인·제품 파일은 제공되지 않았습니다. 배포 공개와 실제 금융 거래 활성화는 별개입니다. GitHub Pages 데모가 공개되어도 결제는 켜지지 않습니다.

## 계정/상품 준비

- [ ] 실제 지원 Windows 버전, 지원 키보드 목록, 실제 제품 스크린샷, 버전·업데이트 내역 확인. 현재 UI 이미지는 CSS 콘셉트이며 기능 보장 자료가 아닙니다.
- [ ] 검증된 EXE 또는 ZIP을 `private/`에 배치. 실제 Windows에서 설치·실행·백신/서명 관련 배포 동작 확인.
- [ ] 계좌번호와 예금주를 `.env`에 설정. 주문 생성 후 구매자에게만 안내합니다. 일반 개인 계좌의 예금주 실명이 송금 과정에서 노출될 수 있고 이를 숨긴다고 보장하지 않습니다. 이 작업에서는 토스뱅크의 해당 계좌 약관을 직접 검토하지 않았습니다.
- [ ] Resend 계정 생성, 본인 도메인의 발신 인증(DNS), 허용 발신 주소, API 키와 현재 할당량/요금 확인. 테스트 수신함으로 발송과 링크 열기 검증. 코드의 SENT는 공급자 접수만 의미합니다.
- [ ] Cloudflare 계정/도메인/터널/Access 설정 및 외부 iPhone 테스트.

## 법적·개인정보 검토 (개별 적용 결론은 미확정)

국세청은 사업개시 전 또는 개시일로부터 20일 이내 사업자등록 신청을 안내합니다. 반복적인 소프트웨어 판매가 본인의 사업에 어떻게 적용되는지 관할 세무서/세무 전문가에게 확인하세요. **개인 개발자·3,000원 판매라는 이유로 등록 의무가 없다고 판단하지 않습니다.** [국세청 사업자등록 신청](https://webtv.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7777&mi=2444)

전자상거래법 제13조는 통신판매업자의 신원과 거래조건 정보 제공을 규정합니다. 본인의 통신판매업 해당 여부, 신고 필요/면제 여부, 판매자 표시 항목과 영수증·세금 신고를 확인하세요. 실명·주소 노출 최소화는 법정 공개 의무를 대체하지 않습니다. [국가법령정보센터 제13조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024961369)

디지털 콘텐츠 청약철회는 제공 개시, 고지·동의, 표시·계약과의 불일치 등 실제 조건에 따라 검토해야 합니다. 일괄 `다운로드 후 환불 불가` 문구로 처리하지 않습니다. [전자상거래법 제17조 관련 본문](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027063323), [표시·계약 불일치 관련 규정](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029561409)

개인정보 고지/동의에는 최소한 아래를 본인의 실제 운영에 맞게 확정하세요. 이 목록은 현재 구현 데이터 흐름을 정리한 검토 양식이며 법률 적합성 확정 의견이 아닙니다.

```text
운영자/개인정보 담당자와 연락처:
수집 항목: 이메일, 입금자명, 주문·입금·다운로드 기록, 동의 시각
이용 목적: 주문·입금 확인, 프로그램 배포, 문의·환불 대응
필수 동의 거부 시: 구매 진행 불가
보유 기간과 법정 보관 근거:
기간 종료 후 DB/로그/백업/모의 우편함 파기 방식:
처리 위탁: 이메일 공급자 및 호스팅/터널 관련 실제 서비스
국외 이전: 수신자/국가/항목/목적/시점·방법/보유 기간/적용 근거
열람·정정·삭제·철회 요청 절차:
가격, 공급 시기, 라이선스 범위, 호환성, 지원 범위:
취소·청약철회·환불 조건과 요청 방법:
```

현재 `web/index.html`의 정책은 모의 안내입니다. 실제 정책을 작성한 뒤 해당 내용을 교체해야 합니다. 토큰 원문이 있는 모의 우편함은 실판매 고객에게 사용하지 않습니다. 원문 입금 알림에는 잔액 등 불필요한 정보를 저장하지 마세요.

## 실제 모드 전환

준비와 사용자 승인 후 `.env`에서 설정합니다. 키와 계좌를 GitHub에 올리지 않습니다.

```dotenv
PUBLIC_BASE_URL=https://store.YOUR-DOMAIN
ALLOWED_ORIGINS=https://store.YOUR-DOMAIN
LIVE_SALES=true
OPERATIONS_REVIEWED=true
MAIL_MODE=resend
RESEND_API_KEY=실제_로컬_키
MAIL_FROM=본인_인증_발신주소
SUPPORT_EMAIL=실제_문의주소
BANK_ACCOUNT=토스뱅크_실제계좌
BANK_HOLDER=실제예금주
PRODUCT_FILE=/absolute/path/to/private/실제상품.zip
PRODUCT_SHA256=검증한_실제상품의_SHA256
PRODUCT_VERSION=실제버전
SUPPORTED_KEYBOARDS=실제확인한_지원목록
```

파일 해시는 `shasum -a 256 private/실제상품.zip`으로 구합니다. 서버는 파일 해시 일치·ZIP/EXE 형식·MOCK-ONLY 표시 미포함·주요 설정을 확인합니다. **이 검증은 실제 프로그램 품질이나 법적 적합성을 검증하지 않으며**, 운영자 검토를 대신하지 않습니다. 설정이 부족하면 서버를 시작하지 않습니다. 실제 모드에서도 관리자 은행 확인은 계속 필수입니다.

## 마지막 검증

- [ ] 실제 정책/판매자 표시와 사용자 승인
- [ ] 실제 상품 해시/다운로드 확인
- [ ] Resend 테스트 메일, 링크 만료·재발급, 반송 상황 확인
- [ ] 아이폰 HTTPS POST 최초/재전송/오프라인 복구
- [ ] Pages 데모에는 구매 폼/개인정보/API 연결이 없음
- [ ] 관리자 Access, 비밀키, 요청 제한, 백업 별도 보관
- [ ] 재부팅 후 로그인·서버·Tunnel·DB·메일 큐 복구

실입금을 이용한 최종 확인은 위 단계가 끝난 뒤 당사자가 직접 수행합니다. 자동 은행 검증을 활성화하려면 계약한 공식 제공자의 검증/서명/거래 ID/중복 방지 테스트를 추가해야 하며, 현재 코드의 source 설정만 바꾸어 활성화할 수 없습니다.
